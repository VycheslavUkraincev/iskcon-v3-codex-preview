# Превью Codex — не сайт

**превью, не сайт**. Отдельный репозиторий для просмотра макета главной.

Источник: `VycheslavUkraincev/iskcon-v3`, ветка `design/codex`, коммит `a4c1e6758677772980f2f056d6fe9215d6284fe6`.

`mockup/` скопирован побайтово без изменений. В `assets/` находятся только 86 файлов, на которые ссылается макет: изображения и все варианты srcset, оригиналы фото для открытия, логотипы, иконки, favicon, словарь, i18n и календарь. Шрифты и OFL находятся внутри неизменённого `mockup/fonts/`. Пути сохранены.

Открывать `/mockup/`; корень перенаправляет туда. Индексация запрещена robots.txt и meta robots. `.nojekyll` отключает преобразования статических файлов.

Другие страницы не включены: сохранённые ссылки на `../courses/`, `../food/`, `../donation/` в этом превью не работают. Внешние ссылки, карта и canonical сохранены как в исходнике. Это публичное превью, без подключения собственного домена и без публикации основного сайта.
